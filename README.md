# Pareidolia-archive
This is a reupload of the application Pareidolia, created for the sake of preservation. Pareidolia was a team-made project created during Summer 2024 at Penn State.

Pareidolia provides a GUI for the steganographic encryption of arbitrary information into encoded images named "vaults". Vaults are locked using passwords chosen by the user, and are secured by an AES algorithm utilizing initialization vectors and salts as to further resist unauthorized decryption. The name and principal of operation are based on the idea of hiding in plain sight, as vaults appear like any other images at a glance.
