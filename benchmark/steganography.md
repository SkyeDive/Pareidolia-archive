# Steganography module benchmark
Module was run on a 1-MP image with 955,829 B (96% of image capacity) of encrypted information,
which was generated from encrypting 716.8 kB (72%) of random plaintext binary data.
Resulting vault file took 1.74 s to write, and 23.66 s to read.
* 1.83 ms / 1 kB write
* 24.75 ms / 1 kB read
